更新日志 · version.json · GitHub

0.4.0

2026-11-06
  • 新增：两键 / 三键组合——同时按住两个键触发另一个动作
  • 新增：按住当功能层——按住某个键时其他键临时换一套映射
  • 新增：修饰键 + 旋钮——按住 ⌃⌥⇧⌘ 再转旋钮，零延迟
  • 新增：命令行 chord / layer / mod 三组命令
  • 这四项高级能力默认关闭，不配置就与原来完全一致

0.3.0

2026-11-06
  • 新增：单击 / 双击 / 长按——同一个键最多绑三种动作；没绑双击的键仍然按下即触发，零延迟
  • 新增：命令行工具 ulanzidial，可在终端直接读改绑定、切配置、看电量
  • 新增：外部改写 config.json 后 App 自动热加载，不用重启
  • 修复：签名标识与 Bundle ID 不一致，导致每次重新编译都要重新授权
  • 改进：旋钮标签不再压住上方按键

0.2.0

2026-11-06
  • 新增：多项操作（按顺序执行，每步可设等待时间）
  • 新增：多套配置，可按前台 App 自动切换
  • 新增：触感反馈与自动休眠设置（写入设备，断电保留）
  • 新增：检查更新（读取本站版本清单，有新版本时提示）
  • 修复：电量一直显示横线（改用标准 GATT 电量特征 0x2A19）
  • 修复：无法录制 ⌥⌘Tab 等被系统预留的快捷键（改用 CGEventTap）
  • 界面：原生液态玻璃效果、设备俯视图、键位标签不再重叠
  • 改名：UlanziDialLite → UlanziDial Native
